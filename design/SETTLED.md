# Claude Design に新しいチャットで頼むとき、最初に貼るもの

このファイルは**貼り付け用**です。Design のチャットが長くなって新しく始めるとき、依頼の前にこの中身をそのまま貼ってください。貼らずに頼むと、**すでに決まったことがゼロから考え直されます**（2026-09-10 に一度やられました。「ゼロから考えて」と書いた依頼が、確定済みの配色と部品を捨てて戻ってきた）。

添付するもの：**M2M Design System**（デザインシステム）と、このファイル。

---

## このアプリは何か

自宅でやったトレーニングを、その場で残しておくための記録帳。サーバーは無く、記録は利用者の端末（IndexedDB）にだけ残る。GitHub Pages で配る静的サイト。**利用者は60代。作者は色弱。**

## 思想（動かせない）

- **点数をつけない。順位をつけない。連続日数を数えない。励まさない。** 淡々と事実だけ。
- **色相だけで意味を伝えない。** 形・枠・明度差を必ず併用する。枠線も WCAG 1.4.11 の 3:1 の対象。
- **比喩や造語で機能を呼ばない。** 「種目の一覧」は一覧であって「庫」ではない。
- **絵が言っていることを文字で繰り返さない。** 犬の絵の下に「イヌ」と書かない。押せば記録される丸に「完了を記録」と書かない。
- **押せる範囲は44**（Apple 44pt / Google 48dp / WCAG AAA 44px）。絵と文字の大きさは変えず、当たりだけ広げる。

## 決まっている画面の作り

| | 決定 |
|---|---|
| メニュー一覧の行 | 行末に**44角の丸ひとつ**。未＝白地＋細い輪郭＋薄い✓＋小さく「つける」、済＝塗り＋白い✓＋実施時刻。横長の塗りボタンは置かない（Apple HIG「目立つボタンは1画面に1〜2個」／M3「filled は1ページに1つ」／実在アプリ9本に例なし） |
| 「一部だけ」 | 行から外し、**行を押して開く画面**に置く。種目の無いメニューは編集が開く |
| 記録の言い方 | **「つける」**。「完了を記録」は使わない |
| メニュー作成の入力順 | **1. 動画の URL → 2. メニュー名 → 3. メモ**。名前欄の下に破線の札「動画から入れた題名」＋「短くする」「空にする」。取得中・失敗・動画なしの3状態あり |
| 題名の折り返し | 一覧・ホーム・履歴とも**2行で打ち切り**（続きは「…」）。全文は編集画面 |
| 空のホーム | 作成画面への入口ではなく**貼る欄そのもの**を置く。3行の手順、控えめな「動画を使わずに作る」、最後に押せない注（Android の共有）。**相棒は置かない** |
| サンプルのメニュー | **同梱しない**。他人の動画の URL を配ることになり、リンクはいつか死ぬ |
| 初回の3問 | ようこそ → 呼び名（任意）→ 相棒（選ばないが既定）。進み具合は**「1 / 3」の数字**（点や色にしない）。「つづける」と、輪郭のボタンの「あとで」。相棒は選んだ瞬間に終了。3問のあとホーム画面に追加の案内へ |
| 呼び名 | 起動時の挨拶で**1回だけ**呼ぶ。そのあとは呼ばない |
| 相棒 | 10体。**名前は付けない**（絵だけ）。動物名も画面に出さない（読み上げ用の alt と aria-label は例外）。1体3コマで数秒に一度まばたきする |
| 相棒の一言 | **見たことを言うだけ。** 出してよい＝時間帯の挨拶／はじめての日／その日まだ無い／久しぶり（何日前）／きょうの件数／今週の日数。出さない＝記録の直後／残り勘定／気持ちの代弁／連続日数／ホーム以外。1日に1つ選んでその日は固定、同じ文は3日空ける。**据え置いた一言が事実と違ってしまったら落として挨拶だけにする** |
| 週の実績 | 44角の正方形、数字13px。4段階は色相を変えず**明度だけ**（#dce3ec / #b3c0d1 / #7e8ea3 / #37465c）。未来は破線で押せない。今日は二重の輪郭 |
| 並べ替え | ▲▼をやめ、**掴み「≡」ひとつ**（当たり44・印15px・`margin-left:-13px`）。長押しで動かす。上下キーでも動く |
| 押せない状態 | `disabled` ではなく **`aria-disabled`**（ネイティブの disabled はフォーカスを外す端末があり、読み上げで状態に到達できない） |
| OS で変える文面 | ホーム画面に追加の案内・ホームの警告バー・書き出し画面の注意。「7日間使わないと消える」は **iOS だけ**の話 |

## 言葉づかい

- 事実を言ったら、**だから何かも言う**（本人の指摘）。「記録はこの端末の中だけにあります」で止めない →「記録は、あなたのスマホの中に保存されます。外に保存されたり、外に出たりすることはありません。」
- **どこに在るかを先に言い、どこに無いかを後に言う**。
- 「完了を記録」「動画だけ」のような帳票語・曖昧語を使わない。「種目情報なし」のように、その行が何を言う場所なのかに沿って書く。
