出し分けの規則
1. 固定の単位＝時間帯（1日固定はやめる）
時間帯を6つに分け、時間帯が変わったら選び直す。同じ時間帯のうちに何度開いても同じ文。日付が変わったらその日の選択はすべて捨てる。朝に選んだ「もうお昼過ぎましたね」系が夜まで残る問題はこれで消える（時刻に触れる文を避ける方法は、本人の例文そのものが時刻に触れているので取らない）。
早朝5:00 〜 6:59　挨拶＝おはようございます 朝7:00 〜 10:59　挨拶＝おはようございます 昼11:00 〜 13:59　挨拶＝こんにちは 午後14:00 〜 17:59　挨拶＝こんにちは 夜18:00 〜 22:59　挨拶＝こんばんは 深夜23:00 〜 4:59　挨拶＝こんばんは
表の「固定」列が「日」の文（元日・はじめての日）だけは、その日いっぱい変えない。
2. 選び方（候補が複数あるとき）
時間帯に入った最初の表示で、次の順に決める。
①first_ever なら F01 だけ。他は見ない。 ②事実系（F）で条件に合い、空ける日数を過ぎているものがあれば、その中から1つ。 ③無ければ、季節（S）・曜日（W）・時間帯（E/M/D/A/N/L）で条件に合い、空ける日数を過ぎているものをひとまとめにして1つ。 ④それも無ければ、その時間帯の挨拶だけ（G01〜G03）。挨拶は空ける日数 0 で常に使える。
「1つ」の選び方は、YYYYMMDD + 時間帯 を種にした乱数。保存が消えても同じ日・同じ時間帯なら同じ文になり、開くたびに変わらない。
同じ日の中で同じ id は2度出さない（時間帯をまたいで同じ文が続かないように）。
3. 空ける日数（表の「空ける」列）
挨拶 G0日（いつでも） 時間帯 E/M/D/A/N/L4日（同じ時間帯に毎日開く人でも4通り以上は回る）。1本だけ2日 曜日 W14日（曜日は7日で戻るので、2週に1回まで） 季節 S10日（月に2〜3回まで）。期間の短いもの（お盆・年末・GW）は7日、元日は365日 事実 F3日。「前回も朝／夜でしたね」は7日（癖に触れる文は頻繫だと監視に聞こえる）
端末に残すのは2つ。hitokoto_last＝{ id: 最後に出した日付 }、hitokoto_today＝{ 日付, 時間帯: { id, 使った事実の写し } }。どちらも書き出しに含めない。
4. 据え置いた文が事実と違ってしまったら
事実系（F）を選んだときは、使った値（today_count・days_since・days_this_week）の写しを一緒に保存する。表示のたびに今の値と比べ、1つでも違えばその時間帯は挨拶だけ（G）に落とす。選び直しはしない（記録の直後に別の気の利いた文へ切り替わると、記録への反応に見える）。
例＝朝に「昨日は 08:10 でしたね」を出し、9時に記録した → today_count が 0→1 に変わったので、10:59 までは「おはようございます。」だけ。11時の昼で改めて選ぶ。
5. 文の作り
挨拶＋ひとこと、の2文まで。ニックネームを含めて 44字以内（15px・幅350pxで2行）。F01 だけ確定済みの文のまま3行を許す。問いかけは1文に1つ、答えなくてよい形（「〜していませんか？」「〜でしたか？」）。「〜しましょう」「〜してください」の指示形は候補に入れていない。天気・祝日・ニュースは使っていない（GW・お盆・年末は日付が固定なので日付だけで判定）。
ヘッダにある日付・曜日をそのまま繰り返さない。曜日に触れるときは、その曜日だから言えること（「週末はゆっくりできましたか？」）だけを足す。
ニックネームを呼ぶ回数
「起動ごとに1回」を「1日に1回」に変える。その日いちばん最初に出す一言の頭に「{ニックネーム}、」を付け、以後その日は付けない。1日に5回開く人が5回呼ばれるのは、人の会話では起きないことなので。
形＝「ゆきさん、おはようございます。…」。F01 だけは「はじめまして、ゆきさん。…」の順。入力された文字をそのまま使い、「さん」を足したり消したりしない（本人が「ゆき」と入れれば「ゆき、おはようございます」になる。初回3問の欄の薄い例文を「例：ゆきさん」にしておくと自然に「さん」まで入る＝Code への提案）。
空なら頭を付けないだけで、文は同じ。事実系に落として挨拶だけになったときも、その日まだ呼んでいなければ「ゆきさん、こんにちは。」と呼んでよい。
候補集（{{ count }}本）
条件に使っている名前は「端末が知っていること」だけです＝band（上の6つ）／hour・minute／weekday／month・day／today_count／today_records[].time／total_minutes／days_since／previous_time（前に記録した日の最後の記録の時刻）／days_this_week／first_ever。文中の「{挨拶}」は時間帯の挨拶に置き換える。同じ配列がこのファイルのロジックにそのまま入っています。

参考にしたもの＝どこを取り、どこを取らなかったか
どうぶつの森の住人＝取った：時間帯・季節・曜日に合わせた短い世間話と、答えなくてよい問いかけ（候補の大半の骨組み）。取らなかった：天気の話（端末が知らない）と、名前を毎回呼ぶこと。
Finch＝取った：時間帯に沿った気づかいの問いかけ（「眠れましたか」「ひと息つけていますか」）。取らなかった：褒め言葉・ポイント・「今日の目標」。
Apple ヘルスケア／フィットネスのまとめ文＝取った：事実を数字1つで短く言う形（「朝のうちに3件」「今週は3日」）。取らなかった：「目標まであと」の残り勘定と、先週との比較。
Duolingo の通知＝取った：1〜2文の短さと口語。取らなかった：急かし（「連続記録が切れます」）と、開いていない日を責める口調。4日ぶりの文は「お変わりありませんでしたか？」で止め、間が空いたことを評価しない。
